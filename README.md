## 📌 Features

- **Dark & Light Mode Toggle:** Seamless theme switching with persistence in `localStorage`.
- **Responsive Layout:** Fluid CSS Grid and Flexbox layouts optimized across mobile, tablet, and desktop viewports.
- **Scroll Reveal Animations:** Hardware-accelerated animations using native `IntersectionObserver`.
- **Accessibility (a11y):** Native support for `prefers-reduced-motion` and clear `:focus-visible` states.
- **Back to Top Button:** Smooth scroll navigation triggered after scrolling 300px.
- **Pure Vanilla Stack:** 100% self-contained code with zero external libraries or CDN dependencies.

---

## 🛠️ Tech Stack

- **HTML5:** Semantic architecture (`<header>`, `<main>`, `<section>`, `<article>`)
- **CSS3:** Custom properties (`:root`), glassmorphism, responsive breakpoints, transitions
- **JavaScript (ES6):** Vanilla DOM manipulation, IntersectionObserver API, Web Storage API

## 🚀 How to Run Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Tejas100132/GitHub-practical-test.git
   cd GitHub-practical-test
   ```

2. **Open in browser:**
   - On macOS:
     ```bash
     open index.html
     ```
   - Or run a local HTTP server:
     ```bash
     python3 -m http.server 8000
     ```
     Navigate to `http://localhost:8000` in your web browser.
